# AI 채팅 v1.1.1 검증 기록

검증일: 2026-10-23. Node.js 24, 데스크톱 Chrome에서 확인했다.

## 통과한 검사

- `npm run check`: 자동 테스트 14개, JavaScript 문법 검사, Git 자격 증명 경로/비밀 패턴 검사 통과.
- `npm run build`: 릴리스 번호·커밋·KST 빌드 시각 생성 및 공개 파일 출력 확인. 별도의 빌드 검사에서 비밀 환경변수와 `dist` 안의 비공개 파일이 출력에 포함되지 않고, 같은 커밋 재빌드 시각이 달라지는지 확인.
- 실제 로컬 시작 명령으로 서버 부팅 및 정적 UI 제공 확인. 외부 제공자 호출 없이 `chatgpt-local` 미연결 상태, 정확한 Host/Origin 검증, 비밀·서버 파일 경로 404, 잘못된 OAuth 콜백의 안전한 리다이렉트 확인.
- 브라우저에서 기존 입력 오류 검증, 요청 등록, 모달 취소·확인, 테이블 검색·정렬·선택·완료·페이지, 목록/상세 왕복, 비동기 성공/실패 시나리오 모두 완료: 6/6.
- 별도의 개발용 모의 계정/모델로 채팅→실제 서버 처리→응답 표시 확인. 초기 전체 8건·표시 4행, 등록 후 전체 9건·표시 4행이 전달됨.
- 입력값 기본 제외, 명시적 입력값 포함, 알려진 키 패턴 마스킹, 테이블 변경 후 전송 정보 미리보기 갱신 확인.
- 응답 중지 시 완료된 답변을 저장하지 않음. 스트림 실패 시 부분 텍스트를 성공 답변으로 표시하지 않음.
- 대화 초기화, 새 질문, 계정 연결 해제 및 미연결 상태의 전송 버튼 비활성화 확인.
- OAuth state·브라우저 세션·재사용·반환 client ID·서명·audience·만료·nonce·subject 검증, 암호화 저장, 갱신 직렬화, 연결 해제/갱신/콜백 경합에 대한 자동 검사 통과.

브라우저 검증용 계정·모델·응답은 모의 값이며 실제 ChatGPT 연결 성공을 뜻하지 않는다. 모의 서버와 자격 증명은 배포 소스에 포함하지 않았다.

## 사용자의 연결 후 확인할 항목

- 실제 ChatGPT 로그인/승인과 계정별 모델 접근, 구독 사용량 한도.
- 실제 OpenAI API 키 호출과 Vercel 배포. 이번 작업에서는 키를 등록하거나 배포하지 않았다.
- 모바일 기기에서 새 채팅 UI의 실제 조작. 반응형 스타일은 포함했으나 이번 브라우저 검증은 데스크톱에서 수행했다.

계정 설정 및 실행 방법은 [연결 안내](ai-chat-setup.md)를 따른다. 배포 버전 표시는 계정 연결 없이도 확인할 수 있다.
